# EVO Digital Solutions Landing Page

## Struktur Folder

- `index.html` — struktur dan konten halaman.
- `css/style.css` — CSS khusus dari file sumber.
- `js/tailwind-config.js` — konfigurasi Tailwind asli.
- `js/script.js` — interaksi portfolio, FAQ, dan form konsultasi.
- `reference/` — referensi desain dan dokumen sumber.

## Cara Menjalankan

1. Ekstrak ZIP.
2. Buka folder `evo_digital_solutions`.
3. Jalankan `index.html` menggunakan browser atau ekstensi Live Server.
4. Koneksi internet diperlukan untuk memuat Tailwind CDN, Google Fonts, Material Symbols, dan gambar eksternal yang digunakan sumber.

## Catatan Pemeliharaan

Struktur, konten, class Tailwind, warna, layout, tautan, dan logika interaksi dari file HTML sumber dipertahankan. CSS dan JavaScript hanya dipindahkan ke file terpisah dan diberi komentar agar lebih mudah dipelajari.
