## Brand & Style

This design system establishes a high-performance corporate tech aesthetic tailored for forward-looking enterprise clients, tech startups, and digital transformation partners. It bridges corporate reliability with the velocity and kinetic energy expressed in the brand's aerodynamic visual mark.

The design movement combines **Corporate Modernism** with subtle **Kinetic Glow Accents**. It relies on disciplined, spacious layouts, clinical white and soft off-white surface layers, sharp data presentation, and high-energy turquoise-to-emerald luminous highlights. The interface conveys technical precision, dependability, and rapid innovation without visual clutter.

## Colors

The palette balances clean, high-luminance canvas backgrounds with dynamic green energy accents and deep slate architecture:

- **Primary (`#18DDA5`)**: The core brand turquoise-mint tone. Used as the leading interactive driver, key callouts, active state indicators, and radiant focal points. When used on white or light surfaces, pair with dark text or apply over deep slate containers (`#172B2F` / `#0D1B1E`) to maintain accessible contrast.
- **Secondary (`#00B887`)**: An anchor emerald green that provides depth, secondary highlights, interactive hover transitions, and directional gradient endpoints alongside the primary turquoise.
- **Tertiary (`#172B2F`) & Deep Contrast Base (`#0D1B1E`)**: Dense teal-tinted slates utilized for heavy navigation bars, hero banner blocks, feature cards, and high-impact data callouts.
- **Neutrals & Surfaces**: Primary background sits on `#FFFFFF` and cool clean canvas `#F8FAFB`. Primary text uses `#111827` (Dark Charcoal) for crisp contrast, supported by `#475569` (Slate) for secondary metadata and structural borders (`#E2E8F0` / `#EDF2F7`).

## Typography

The typography couples the modern, geometric energy of **Plus Jakarta Sans** for headlines and titles with the disciplined neutral clarity of **Inter** for sustained text, data tables, and interactive labels.

- **Headlines & Titles (Plus Jakarta Sans)**: Rendered in semibold and bold weights with subtle negative tracking. This maintains the clean, tech-forward momentum echoed in the logo's streamlined forms.
- **Body & Data (Inter)**: Built for neutral readability across high-density analytics, case studies, and enterprise product workflows.
- **Styling Rules**: Section subheads and category indicators utilize `label-sm` with uppercase transformation and a subtle `0.04em` letter-spacing for clean architectural categorization.

## Layout & Spacing

The layout operates on a standard **12-column responsive fluid grid** with defined boundary constraints:

- **Desktop (1200px+)**: 12 columns, `gutter-lg` (2rem / 32px), `margin-desktop` (3rem / 48px), max-width bounded at 1280px for standard agency content and 1440px for broad analytics dashboards.
- **Tablet (768px - 1199px)**: 8 columns, `gutter` (1.5rem / 24px), `margin` (2rem / 32px).
- **Mobile (< 768px)**: 4 columns, `gutter-sm` (1rem / 16px), `margin-mobile` (1rem / 16px).

Elements conform strictly to an 8px spacing rhythm (`space-xs` through `space-3xl`). Layouts emphasize generous vertical breathing room between narrative sections (`space-3xl`) while keeping component interiors compact and structured.

## Elevation & Depth

Visual hierarchy uses a refined combination of crisp hairline borders, light slate surface containers, and focused mint/emerald ambient diffusions:

- **Level 0 (Flat Surface)**: Pure background (`#F8FAFB`) or white baseline (`#FFFFFF`) with 1px border (`#E2E8F0`).
- **Level 1 (Cards & Modules)**: Background `#FFFFFF` framed by a 1px border (`rgba(23, 43, 47, 0.08)`), combined with a low-intensity ambient drop: `0 4px 16px -2px rgba(17, 24, 39, 0.04)`.
- **Level 2 (Interactive Hover / Flyouts)**: Elevated container applying `0 12px 28px -4px rgba(17, 24, 39, 0.08)`, border adjusting to `rgba(24, 221, 165, 0.35)`.
- **Level 3 (Dark Accent Blocks & Popovers)**: Containers set against deep charcoal/slate (`#172B2F`) utilizing an interior micro-glow border (`inset 0 1px 0 rgba(24, 221, 165, 0.25)`) and a diffused outer shadow `0 20px 35px -8px rgba(13, 27, 30, 0.4)`.
- **Signature Gradient Aura**: Featured action items, active badges, or hero graphic modules feature a soft backdrop bloom using `radial-gradient(circle at top left, rgba(24, 221, 165, 0.12), transparent 70%)`.

## Shapes

The geometric form language adopts **Level 2 Roundedness** (0.5rem / 8px baseline radius), establishing clean architectural stability while echoing the aerodynamic curves of the brand identity:

- **Default Elements (`rounded-md` / 0.5rem / 8px)**: Standard buttons, text inputs, table cell enclosures, and basic interactive controls.
- **Containers & Cards (`rounded-lg` / 1rem / 16px)**: Information cards, metric showcases, modals, and content blocks.
- **Hero Enclosures (`rounded-xl` / 1.5rem / 24px)**: Outer boundary media frames and primary hero showcase sections.
- **Pill Elements (`rounded-full` / 9999px)**: Category tags, status indicators, modern agency UI badges, and compact floating actions.

## Components

### Buttons
- **Primary**: Background filled with gradient `linear-gradient(135deg, #18DDA5 0%, #00B887 100%)`, text `#0D1B1E` (weight 600), radius `8px`. Hover shifts elevation with subtle mint drop glow `0 4px 14px rgba(24, 221, 165, 0.35)`.
- **Secondary / Slate**: Background `#172B2F`, text `#FFFFFF`, border `1px solid rgba(24, 221, 165, 0.2)`. On hover, border shifts to `#18DDA5`.
- **Ghost / Outline**: Transparent fill, 1px border `#E2E8F0`, text `#111827`. Hover applies `#F8FAFB` fill with `#00B887` text.

### Modern Badges & Chips
- **Status Badges**: Pill-shaped (`rounded-full`), padding `4px 12px`, typography `label-sm`. Background `rgba(24, 221, 165, 0.12)`, text `#00B887`, and border `1px solid rgba(24, 221, 165, 0.28)`. An optional 6px pulsing emerald indicator dot precedes text.
- **Filter Chips**: 8px rounded container, background `#FFFFFF`, border `1px solid #E2E8F0`, text `#475569`. Active state transitions to background `#172B2F`, text `#18DDA5`, and border `#172B2F`.

### Cards
- **Base White Card**: Background `#FFFFFF`, 16px radius (`rounded-lg`), 1px border `#E2E8F0`, padding `24px`.
- **High-Impact Featured Card**: Background `#172B2F`, 16px radius, border `1px solid rgba(24, 221, 165, 0.2)`. Features a top-right ambient turquoise glow overlay, text `#FFFFFF`, subtext `#94A3B8`.

### Input Fields & Controls
- **Inputs**: Height `44px`, radius `8px`, background `#FFFFFF`, border `1px solid #CBD5E1`, text `#111827`, placeholder `#94A3B8`. Focus state applies border `#18DDA5` with a `0 0 0 3px rgba(24, 221, 165, 0.2)` ring.
- **Checkboxes & Radios**: 18px dimensions, border `1.5px solid #CBD5E1`. Checked state fills `#00B887` with crisp white iconography.

### Lists & Tables
- **List Items**: Separated by hairline borders `#F1F5F9`. Hover activates an ultra-light tint (`#F8FAFB`).
- **Data Tables**: Header rows set against `#F8FAFB` with `label-sm` uppercase text in `#475569`. Metric cells emphasize strong numeric typography in `Plus Jakarta Sans`.

### Metrics & KPI Displays
- Large numerical counters in `headline-xl` (`Plus Jakarta Sans`), highlighted with an emerald trend pill (`+24%`) indicating growth velocity.
